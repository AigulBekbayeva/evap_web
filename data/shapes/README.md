# Контур водоёма

Положите сюда **один** векторный файл с контуром озера.

Поддерживаются: `.shp` (вместе с `.dbf`, `.shx`, **`.prj`**), `.geojson`, `.gpkg`.

Требования:

- **Система координат обязана быть задана.** Для шейп-файла это означает
  наличие `.prj`. Без него пайплайн остановится с понятной ошибкой, а не
  молча посчитает всё в неверной проекции.
- Любая проекция подойдёт — модуль сам приведёт к EPSG:4326.
- Несколько полигонов (система прудов) — нормально, они объединяются.
- Контур должен соответствовать **среднему многолетнему** урезу воды.
  Если он снят на конкретную дату при аномальном уровне, площадь будет
  систематически смещена, а с ней и объёмы в водном балансе.

После того как файл на месте:

```bash
evap inspect
```

Команда покажет площадь, центроид, число частей и оценит, сколько ячеек
ERA5-Land и пикселей Landsat приходится на акваторию. Это первое, что надо
сделать: если озеро меньше одной ячейки ERA5-Land, читайте раздел
«Известные ограничения» в README.

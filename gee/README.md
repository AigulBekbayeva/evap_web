# Скрипты Earth Engine

Пайплайн выгружает данные через Python API (`earthengine-api`), поэтому эти
скрипты для работы не нужны. Они лежат здесь для интерактивной проверки в
[Code Editor](https://code.earthengine.google.com) — это самый быстрый способ
посмотреть глазами, что именно попадает в расчёт.

- `explore_lswt.js` — карта температуры воды на выбранную дату и график ряда

Порядок: открыть Code Editor, вставить скрипт, заменить координаты на свои.

What is being computed

Open-water evaporation by the Penman method: the sum of a radiative and an aerodynamic term. Meteorology comes from the ERA5 reanalysis (ECMWF) through the Open-Meteo Archive API.
Water temperature is modelled, not measured: the heat balance of the water column is integrated using the depth you provide. This is far better than assuming water temperature equals air temperature — thermal inertia is reproduced, and heat storage enters the calculation in a physically meaningful way.
There is nothing to validate against. Depth remains a free parameter and no ground measurements are involved. Comparing years and months against each other is safe — the systematic error is the same for all of them. Treat absolute values as an order-of-magnitude estimate. If you need accuracy, the Python version of this project recovers depth from satellite water-surface temperature (Landsat, MODIS).
Downwelling longwave radiation is not served by Open-Meteo, so it is estimated from temperature, humidity and cloud cover using the Brunt formula — roughly 10 % accuracy.
